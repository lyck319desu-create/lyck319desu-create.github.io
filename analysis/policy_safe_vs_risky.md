# 手本に寄せるときの「安全な範囲」と「危ない範囲」

調査日：2026-10-18　／　出典は YouTube ヘルプ（公式）と日本の著作権法の一般原則。末尾に出典一覧。

---

## 1. 結論（先に）

1. **型・構成・題材選び・冒頭の言い回しの「パターン」は真似してよい**。著作権が守るのは具体的な「表現」で、アイデアや手法は守られない。YouTube の収益化基準も「他人の動画をそのまま使うこと」と「中身が入れ替え可能な量産」を問題にしており、構成を参考にすること自体は対象外。
2. **一番の危険は著作権ではなく「自分のチャンネル内の繰り返し」**。noah 型（VOICEVOX 音声＋数字で断言＋3選）を1日2本ペースで回すと、「テンプレートで作ったように見える」「動画ごとの違いが少ない」という**不自然なコンテンツ（旧：繰り返しの多いコンテンツ）**の基準に引っかかりやすい。これは**チャンネル全体の収益化停止**につながる。
3. **台本の文章・映像・画像・BGM を他人の動画から持ってくるのは即アウト側**。Content ID の申し立て（収益が相手に行く）や著作権侵害の警告（3回で90日以内ならチャンネル削除対象）につながる。

---

## 2. 一覧：どこまで寄せてよいか

| 寄せ方 | 判定 | 理由（根拠） |
|---|---|---|
| 題名の型（「なぜ〜なのか…!?」「もし〜したら」「XX%が〜」） | ✅ 安全 | 型は表現ではなく手法。著作権の保護対象外 |
| 冒頭の一言の「型」（数字で断言する、問いかける） | ✅ 安全 | 同上。言い回しを自分の言葉で作れば問題なし |
| 構成の順番（フック→3つの事実→オチ、60秒前後） | ✅ 安全 | 構成の手法は保護されない。YouTube も「同じイントロ・アウトロでも中身が違えば可」と明記 |
| 題材（同じ国・同じ歴史的事実を扱う） | ✅ 安全 | 事実そのものは誰のものでもない。自分で調べ直して自分の切り口で語る |
| 画面の作り（地図＋字幕＋合成音声という見せ方） | ✅ 安全 | 見せ方の様式は保護されない。素材は自作・フリー・ライセンス済みを使う |
| 同じ題材で、相手の動画にない新情報や日本との関連を足す | ✅ 安全（むしろ推奨） | 「独自の解説・付加価値」が収益化の条件そのもの |
| 相手の台本を言い換えながら順番・例え・オチまで一致させる | ⚠️ 危ない | 文の並びや独自の例え・オチは「表現上の本質的な特徴」になりうる。語尾を変えただけでは翻案（改変した複製）扱いになるおそれ |
| 同じ題材を、相手と同じ資料・同じ順・同じ数字で再現 | ⚠️ 危ない | 個別の事実はよいが、選び方と並べ方まで同じだと創作性のある部分の再現になりやすい |
| 自分のチャンネルで同じ型を毎回ほぼ同じ台詞・同じ流れで量産 | ⚠️ 危ない | 「動画ごとの違いが少ない」「テンプレートで量産した印象の AI 生成」は収益化不可と明記 |
| 同じキャラが毎回同じ状況で同じ結末になる連作 | ⚠️ 危ない | YouTube が名指しで不可の例に挙げている |
| AI に台本を自動生成させ、そのまま読み上げて大量投稿 | ⚠️ 危ない | 同上。AI の利用自体は可だが「汎用・独自性のないテンプレート」による量産は不可 |
| 他人の動画の映像・画像・字幕画面をそのまま使う（短くても） | ❌ アウト | 再利用コンテンツ。Shorts では再生数が収益の対象から外れる。Content ID の申し立て・削除の対象 |
| 他人のショートを集めた総まとめ（コンピレーション） | ❌ アウト | 「他の SNS から集めた短い動画」は名指しで不可。許可があっても不可 |
| 他人の台本を書き写して読み上げる | ❌ アウト | 文章の複製。著作権侵害の警告の対象 |
| 他人の BGM・効果音を無断で使う | ❌ アウト | Content ID で自動検出されやすい。YouTube オーディオライブラリかライセンス済み音源を使う |

## 3. 2つの仕組みの違い（何が起きるか）

### A. 収益化の基準（YouTube パートナープログラム）

罰は「削除」ではなく**収益化の停止・不承認**。審査のときにチャンネル全体を見られる。

- **再利用コンテンツ**：他人の動画や他サイトの素材を、大きな変更を加えずに使うこと。
  - 不可の例：番組の名場面を説明なしでつないだもの、他の SNS から集めた短い動画、いろいろな歌手の曲を集めたもの（**許可があっても不可**）、ダウンロードしてほぼそのまま上げたもの。
  - 可の例：批評のための切り抜き、元動画に自分のコメントを入れるリアクション、投稿者本人が主に出ている動画。
  - 罰：**チャンネル全体の収益化が外れることがある**。
- **不自然なコンテンツ**（2025年7月15日に「繰り返しの多いコンテンツ」から名前が変わった。中身は同じ）：テンプレートで作ったように見える、動画ごとに入れ替えても気づかない内容。
  - 不可の例：教育的価値・解説・ストーリーが少なく違いが小さい動画の連続、同じ状況・同じ結末の繰り返し、汎用テンプレートで量産した印象の AI 生成動画。
  - 可の例：イントロとアウトロが毎回同じでも本編が違う、各動画に別の筋・焦点・テーマがある。
  - 罰：**パートナープログラムで収益化できない**。
- **Shorts の追加ルール**：他人の映画やテレビの未編集の切り抜き、他の投稿者の動画の再アップ、独自要素のない総まとめは、**再生数が収益分配の対象外**になる。

### B. 著作権の仕組み

| | 著作権の申し立て（Content ID） | 著作権侵害の警告（ストライク） |
|---|---|---|
| きっかけ | 自動照合で一致が見つかる | 権利者からの削除リクエスト（法的手続き） |
| 起きること | 権利者の設定で「ブロック」「相手が広告収益を取る」「再生データの追跡」のどれか | 動画が削除され、チャンネルに警告が1つ付く |
| チャンネルへの影響 | 直接の罰はない（その動画の収益が相手に行く） | **90日以内に3つでアカウントと関連チャンネルが削除対象**。新しいチャンネルも作れなくなる |
| 消し方 | 異議申し立て | 著作権講座（4問）を受けて90日待つ／相手に取り下げてもらう／誤りなら反論通知。**動画を消しても警告は消えない**（予約型の削除リクエストなら7日以内の削除で回避可） |

## 4. 日本の著作権法で「パクってよい部分」の線引き

- 著作権法が守るのは「思想又は感情を**創作的に表現**したもの」（著作権法2条1項1号）。**アイデア・事実・手法・作風・ジャンルの型は守られない**。
- 他人の作品を元にした作品が侵害になるかは、最高裁「江差追分事件」（平成13年6月28日判決）の基準で判断されるのが一般的：**元の作品の「表現上の本質的な特徴」を直接感じ取れるかどうか**。事実やアイデアなど表現でない部分が同じなだけなら侵害にならない。
- ショートに当てはめると：**「何を扱うか」「どの順で見せるか」の型は自由、「どんな文章で、どんな例えで、どんなオチで言うか」は相手のもの**。（法律の解釈は一般論としての整理で、個別の判断は専門家の確認が必要）

## 5. このチャンネルでの運用ルール（提案）

1. **台本は手本を見ながら書かない**。手本から抜くのは「題名の型・冒頭の型・構成の順・長さ」だけ（[benchmark_noah_vs_chiri.md](benchmark_noah_vs_chiri.md) と同じ方針）。事実は一次資料や百科事典で自分で調べ直す。
2. **毎回1つ「手本にない要素」を入れる**：日本とのつながり、独自の比較、最新の数字、自作の地図や図など。これが再利用・不自然コンテンツ両方の対策になる。
3. **型の固定は「イントロとアウトロ」まで**。本編の流れ・台詞の言い回しは毎回変える。同じ台詞の使い回しを避けるため、使ったフックを一覧で管理する。
4. **素材は自作・フリー素材・YouTube オーディオライブラリのみ**。他人の動画のスクリーンショットも使わない。
5. **AI は下書きと調べ物の補助まで**。生成した台本はそのまま読ませず、必ず自分の切り口と確認した事実に書き換える。実在の場所や出来事をリアルに加工・合成した映像を使う場合は、アップロード時の「改変・合成コンテンツ」の開示をオンにする。
6. **合成音声（VOICEVOX 等）を使う場合は各キャラクターの利用規約のクレジット表記を守る**（例：概要欄に「VOICEVOX:キャラクター名」）。※規約はキャラクターごとに異なるので使う前に確認。
