## 1. 結論

1. **検証型で伸びるのは、題材が「毎日〔自重の種目〕〔回数〕を〔期間〕続けた体」のとき。** キント道場の 10万回超えは「50歳が毎日腕立て30回を1年続けた体を検証した」（17.2万）だけ。2番目は「毎日30秒ぶら下がるだけで体はどうなるのか」（6.8万）。同じ検証型の「やり続けるイッチ」でも、筋トレの回（40本）の中央値は 6.4万回で、ほかの題材（290本、2.05万回）の約3倍。
2. **お金と時間の数字も伸びる。** 「タンパク質20gの値段を15食品で検証してランキングにした」4.4万、「筋肉1kgを増やすのに何ヶ月かかるか検証したら残酷だった」3.6万。
3. **食事・睡眠・歩数・国のデータは伸びない。** キント道場の 10月の食事の回は 362〜2,141回。すけマッチョは筋トレの題材に絞るのが良い。
4. **同じ題材でも、3分では伸びず、7分にすると伸びた。** キント道場の「毎日腕立て100回を1年続けた体」（3分29秒）は 691回、「50歳が毎日腕立て30回を1年続けた体」（7分25秒）は 17.2万回。違いは、長さ・回数（30回なら自分にもできる）・「50歳が」と見る人を名指ししたこと・サムネ。
5. **サムネの勝ちパターン：暗い青緑の背景、顔のない筋肉の人物、上に白い太字で種目と期間（期間だけ赤）、下に「その結果…」。** キント道場で伸びた2本は、どちらもこの人物。すけマッチョの「顔のない筋肉の人物」をそのまま主役にできる。

## 6. すけマッチョの検証型の作り方（案）

| 項目 | 案 |
|---|---|
| 型 | キント道場の「計算で検証」。主人公は平均的な体の人で、研究の数字で1か月後・3か月後・1年後を計算する |
| 題材 | 「毎日〔自重の種目〕〔続けられる回数〕を〔期間〕続けた体」を軸に、「筋肉／腹筋が〇〇するのに何ヶ月かかるか」「〇〇の値段ランキング」を混ぜる。食事・睡眠だけの回はやらない |
| 長さ | 8〜10分（キント道場の7〜8分より少し長く。長尺メインの方針に合わせる） |
| 章立て | 問い → 現実 → 検算1〜3 → 一番意外な数字 → あなたの設計図。章の名前・言い回しは自分で作る |
| 主役 | すけマッチョ（顔のない筋肉の人物）。サムネも本編も、すけマッチョが種目をしている絵 |

### 最初の題材案（キント道場・イッチと被らない言い方にする）

1. 毎日スクワット30回を1年続けた体を検証した（イッチの1ヶ月の回が 45.6万。キント道場はまだやっていない）
2. 腹筋が割れるまで何ヶ月かかるか、体脂肪率から検証した
3. 毎日プランク1分を1年続けた体を検証した
4. 40代が毎日懸垂を続けたら、何ヶ月で10回できるか検証した
5. 筋肉1kgあたりの値段を、プロテイン・鶏むね・卵で検証した

## 7. 気をつけること

- キント道場の題名・章の名前・説明欄の文はそのまま使わない。数字の計算と出典は自分で確かめる。
- 計算で出した「1年後の体」は推定だとはっきり言う（キント道場も説明欄に「研究のモデルを主人公に当てはめた計算です。実際の減り方は人によって違います」と書いている）。
- やり続けるイッチは作り話の体験談（説明欄に「エンターテイメントとして」とある）。すけマッチョでは、作り話を本当の体験のように見せない。
- 健康の話なので免責を入れる。
- キント道場も 25本中 10万回超えは1本だけ。検証型は当たり外れが大きい。最初の8本は、伸びた題材の近くに絞る。
