# ショートの視聴維持率：離脱の理由と直し方（地図の理由）

最初の調査：2026-10-22　／　材料：齊木さんの YouTube Studio スクショ（概要タブ）2本
この文書は**毎回足していく**。新しい回のデータが来たら「4. 記録」に1行足し、ルールが変わったら「3. ルール」を直す。

---

## 1. 結論（先に）

1. **「維持率が高いのに伸びない」の一番の理由は、維持率の外にある。** 概要タブの維持率は「見始めた人」の中での数字。おすすめに広がるかを先に決めるのは、その手前の **「視聴した／スワイプして離れた」の割合**（エンゲージメントタブ）。
   - **【2026-10-22 追記・32本のデータで修正】** 10月からの地形シリーズ26本は「視聴を継続」が全部 56〜68% にそろっていて、再生数との関係はほぼ無かった（相関 0.12）。差がついたのは9月の県境シリーズ（35〜48%）との間だけ。今の地図の理由で再生数を分けているのは、**話題の大きさ**と**平均視聴率**（相関 0.53）。詳しくは「6.」。
2. **話題の大きさの差がそのまま出ている。** 日本全体の話（7割は山）は維持率86.9%で14,384回、1か所の話（鹿児島湾）は維持率90.3%なのに8,573回。維持率が高い方が負けている。これは Issue #3 と topic_size_check_benchmarks.md の結論と同じ（＝改善チームはすでに把握済み。ここでは重ねない）。
3. **最後の約1秒で 68%→41% に落ちる（鹿児島湾）のは「終わりの合図」が出ているから。** 人は終わったと分かった瞬間にスワイプする。終わりの合図を消して、最後の言葉が最初の言葉につながる形にすれば、落ちる人がループに回り、平均が100%に近づく。
4. **途中の離脱は「答えが出た瞬間」に起きている（7割は山：0:19〜0:20 に 95%→79%）。** 題名の問いの答えを中盤で言い切ると、知りたかったことが済んだ人が抜ける。答えは最後まで取っておくか、答えの直後に「もっと大きな次の謎」を置く。
5. **登録への変わり方が弱い。** 7割は山は14,384回で登録+4（0.03%）。見終わっても「この先も見たい」理由がない。

## 3. ルール（司令塔・改善チームがそのまま使える形）

### A. 最後の2〜3秒（ループ）

- **終わりの合図を置かない**：「チャンネル登録してね」「以上」「おわり」、音楽のフェードアウト、BGMの終止、画面の暗転、止め絵、エンドカード風の画面。どれも「終わった」と知らせてスワイプさせる。
- **最後の一言を最初の一言につなげる**：最後の文を途中で切り、頭の文が続きになるようにする（例の型：最後「だから鹿児島湾は——」→頭「巨大噴火の穴なんです」）。2周目に入っても違和感がない形にする。
- **最後の絵と最初の絵を同じにする**：同じ地図・同じ寄り具合で終える。切れ目が分からないほどループに入る人が増える。
- **BGMは最後まで同じ音量で鳴らし続ける**。止めない。
- 登録の呼びかけを入れるなら**中盤**（離脱の少ない所）か、入れない。

### B. 途中の離脱

- **題名の問いの答えは最後の5秒まで言い切らない**。途中で出すなら、その直後に「でも本当に驚くのはここから」の型で、もっと大きな次の謎を置く（答え→次の謎→答え の階段）。
- **場面の切り替えで間を空けない**：0.3秒以上の無音・止め絵を作らない。切り替えの瞬間に次の言葉が始まっているようにする。
- **2〜3秒に1回、画面に変化**（寄る・線が伸びる・数字が出る）。地図の止め絵が長いと抜ける。

### C. 最初の1〜2秒（スワイプされるか）

- ショートの画面では題名はほぼ読まれない。**最初の絵と最初の一言が題名の代わり**。
- 一言目で「大きな主語 × 意外な一点」を言い切る（noah 型の数字の断言）。前置き・あいさつ・チャンネル名は入れない。
- 最初の絵に**誰でも分かる目印**（日本列島の形・富士山・桜島）を置く。ジオレンズで富士山の回だけ伸びたのと同じ理屈。

### D. 平均を100%超えにするには（正直な見立て）

- 平均視聴率が100%を超えるのは、ループで2周目に入る人が多い時だけ。**45秒前後の解説で毎回100%超えは難しい**。今の 87〜90% はすでに高い部類。
- 100%超えを狙う回は、**20〜30秒の短い版**を作る（1つの驚きだけ・答えで終わってそのまま頭につながる形）。長さを変えるのは伸びの比較にもなる。
- おすすめ：週に1本だけ短い版を混ぜ、「視聴した割合」と平均視聴率を45秒版と比べる。

### E. 維持率が高いのに伸びない回の見分け方

順番に見る。上で止まったらそこが理由。

1. **視聴した割合が低い**（目安：60%台以下。70%以上なら強い。※一般に言われる目安で、このチャンネルの値で後から直す）→ 最初の1秒と最初の絵の問題（ルールC）。
2. **話題が小さい**（1つの県・町の話）→ 題材の問題。改善チームの基準（Issue #3）で弾く。
3. **高評価・共有・コメントが少ない**（エンゲージメントタブ）→ 誰かに言いたくなる一点がない。最後に「日本の暮らしに返す」一言を足す。
4. **登録が増えない**（目安：1万回で+10未満）→ 続きを見る理由がない。「積み上がる日本地図」（topic_size_check_benchmarks.md の提案）で回をまたぐ理由を作る。
5. どれでもない → 公開時間・投稿の間隔など配られ方の問題。数本たまってから比べる。

- **改善チーム（司令塔側）がすでに見ていること**：話題の大きさ、台本の形（結論→なぜ→説明）、公開時間の差（Issue #3）。ここでは繰り返さない。

## 6. 32本まとめて見た結果（2026-10-22、Studio から取得）

元データ：`analysis/raw/chizu_retention/*.json`（公開2〜28日のショート32本。維持率はグラフの読み取りで±1〜2%）

### 再生数と関係が強いもの・弱いもの（10月の地形シリーズ26本、再生数は対数で比較）

| 数字 | 再生数との相関 | 読み方 |
|---|---|---|
| 平均視聴率 | **0.53** | 高い回ほど伸びている。上位4本（日本列島 101%・四国と関西 112%・関東平野 100%・伊豆 134%）はどれも 100% 前後以上 |
| 視聴を継続（スワイプされなかった割合） | 0.12 | 全部 56〜68% にそろっていて差がつかない。9月の県境シリーズ（35〜48%）とは大差 |
| 長さ | −0.16 | 22秒の伊豆半島が 134%・6.7万回。短いほど平均視聴率は上がる |
| 高評価の割合 | −0.51 | 伸びた回ほど低い（伸びると、知らない人に広く配られるため。原因ではない） |
| 共有の割合 | ほぼ0 | 0〜0.3%。どの回も少ない |

### 最後に崩れる回が6本ある

最後の5%で 13〜34 ポイント落ちる回：**富士山の中に山が3つ（63→29%）・鹿児島湾（71→40%）・北海道（68→39%）・関東平野（81→53%）・阿蘇の火砕流（80→65%）・ハワイ（54→40%）・和歌山（57→44%）**。
残りの約20本は最後の落ちが 0〜9 ポイントしかない。**同じチャンネル・同じ作り方なのに、この7本だけ終わり方が違う**はず。改善チームに、この7本とそれ以外で最後の2秒（言葉・BGM・画面）の違いを出してもらう（Issue #14）。
この崩れは平均視聴率を 3〜5 ポイント下げる。ただ関東平野は崩れても10万回なので、伸びを決める一番の理由ではない。

### 登録への変わり方（1万回あたり）

- 高い：日本の真ん中の溝 10.9・鹿児島湾 9.4・四国と関西 8.3（ハワイ・日本海などは再生が少ないので数字がぶれる）
- 低い：**日本の7割は山 2.1・津軽海峡のクマ 2.2・浜名湖 3.3・伊豆 3.9**
- 「なぜ〜」「〜がある」で地形の仕組みを見せる回は登録が多い。豆知識寄り（クマ）や、答えが一言で済む回（7割は山）は少ない（推定）。

### 公開から日が浅い回に注意

浜名湖・桜島（2日）、津軽海峡・ハワイ（3日）はまだ伸びている途中。7日たってから判断する。
