## 1. 結論

1. **手本は「ホワイトマン【WORKOUT】」1本に絞る（推奨。オーナーに確認中）。** ショート（中央値 7.4万回）と、2〜3分の「〇〇を毎日△回行うとどうなるのか」長尺（上位 210万・200万・93万回）の両方がある日本語の筋トレ図解で、今の「毎日ショート＋週3長尺」の体制のまま寄せられる。すけマッチョで一番伸びた FT-01（4,354回）も同じ型。
2. **今まで写していたのは「台本の流れ」だけで、見た目とテンポは写していなかった。** そこを寄せるのが今回の作り直しの中心。具体的には、灰色の無地背景＋白い無個性の人物＋黒の極太2行の題名カード＋約1秒ごとの絵替え。
3. **チャンネルの看板がまだ前身の「見えないしくみ図鑑」のまま。** バナーは紺地に箱のロゴで「いつもの『なぜ？』を、動く図解で。」。筋トレの棚として見えないので、名前・アイコン・バナー・説明文を全部替える。
4. **長尺は 2〜3分（120〜190秒）に縮める。** ホワイトマンの大ヒット長尺は 143〜187秒、メタルくんも 113〜153秒。ホワイトマン自身の最近の 14〜15分の長尺は 1.7万回止まり。
5. 1本に1つ、手本に無い要素を必ず入れる（2025-07 の「繰り返しの多いコンテンツ」対策。policy_safe_vs_risky.md）。おすすめは「数字の検算カード」（下の 6 節）。

## 4. ホワイトマンの型（寄せる中身）

### 4-1. 長尺「〇〇を毎日△回行うとどうなるのか」（120〜190秒・横長）

| 秒 | 役割 | 画面 |
|---|---|---|
| 0〜5 | 問い：「毎日〇〇を△回やったら、体はどうなる？」 | 灰色の無地、上に黒の極太2行、下に人物が種目をしている全身 |
| 5〜20 | 前提：誰が・何を・どれくらい | 人物の決めポーズ。1〜2秒ごとに絵替え |
| 20〜60 | 時間の流れ①：最初の1週間（筋肉痛・震え） | 「1週間目」などの章の札。変化の1語を大きく単独で |
| 60〜110 | 時間の流れ②：2〜4週間（慣れ・見た目の変化） | 効く部位を赤で塗る。解剖図・写真の差し込み |
| 110〜150 | ひねり：「でも〜だけだと…」（偏り・頭打ち） | 暗い背景の1語カード |
| 150〜180 | 解決と締め：反対の動き・別の動画へ | 先生役が指さし、関連動画の絵 |

- 話す速さ：約7.5〜8字/秒。画面は約1〜1.5秒に1回、絵・寄り・塗り色・札のどれかが替わる。
- 題名の型：「〇〇を毎日△回行うとどうなるのか」「毎日〇〇を1ヶ月続けたらどうなるのか」。答えは題名に書かない。
- サムネ：灰色の背景、人物の全身または上半身、黒の極太2行（1行目に種目と回数、2行目に「どうなる？」）。キーワード1語だけ赤。

### 4-2. ショートの3つの型（30〜50秒・縦）

| 型 | 例（手本） | 流れ |
|---|---|---|
| A 毎日やったら | 【胸だけ鍛えると】もし毎日腕立て伏せを100回やったら（29万） | 問い→最初は→数週間後→でも（ひねり）→なぜなら→だから |
| B 正しいフォーム | 【正しい腕立て伏せ】あなたの腕立て伏せは間違っています（23万） | 題名カード→断言→思い込みの否定→要点3〜4つを1語札で→成果の約束 |
| C 1つの数字で答える | 筋トレの休憩は何秒が正解？（9.1万） | 問い→対象の言い当て→両側の失敗→答えの数字を大きく単独で→例外1つ→問い返し |

いずれも 0コマ目から「題名の2行＋人物の絵」が両方出ている（文字だけ・絵だけで始めない）。

## 5. どこまで寄せるか

| 寄せる（型・様式。著作権で守られない範囲） | 寄せない（写すと権利・規約で危ない） |
|---|---|
| 灰色の無地背景・白い無個性の人物という様式 | ホワイトマンの人物の絵そのもの、先生役（スーツ）のデザイン |
| 黒の極太2行の題名カード、赤（間違い）→緑（正しい）→黄（ご褒美）の色の決まり | 字幕・ナレーションの文、決めぜりふ |
| 約1秒ごとの絵替え、1語の大きな札、章の札 | 音楽・効果音・声 |
| 題名の形（「〜を毎日△回行うとどうなるのか」）と尺 | 題名の文そのもの（題材を変えるか語順を変える） |
| サムネの構図と色の配置 | サムネの絵 |

人物は「すけマッチョ」自身を、白い無個性の体に描き直す（顔は丸と線だけ、筋肉の線は減らす）。今の解剖図風の人物は情報が多く、縮小時に読みにくい。

## 6. 1本に1つの独自要素（必須）

候補。毎本どれか1つを台本に書いておく。

1. **数字の検算カード**：「毎日30回×30日＝900回、1回2秒なら合計30分」のように、その動画の数字をすけマッチョ自身が計算して見せる（キント道場の強みを取り込む。ホワイトマンには無い）。
2. **出典の札**：根拠の論文・公的資料を画面の端に小さく出す（今のすけマッチョの方針の継続）。
3. **日本の生活に合わせた例**：通勤・デスクワーク・こたつなど、場面を日本の日常に置く。

## 9. 気をつけること

- **WGM（Workout Gym Music）も「筋トレの長尺」を作る予定（同日のオーナーの指示）。** 同じ題材で2チャンネルがぶつからないよう、すけマッチョは「図解で答える」、WGM は「一緒にやる・聞きながら鍛える」側に分けるのが良い（オーナーに確認する事項）。
- 見た目を大きく変えると、最初の数本は今の視聴者にも新しく出るので数字が揺れる。判断は 2週間・ショート14本・長尺6本を見てから。
- 再生数は題材・時期・初動の視聴者で変わる。この型で必ず伸びるとは言えない。
