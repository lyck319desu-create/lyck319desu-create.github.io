# 分析の置き場

分析プロジェクト（claude.ai の「ショート動画 収益化ラボ」）が書いた分析を置く。制作側（Mac の司令塔）はここを読む。

- `../structures.json` …… 伸びた動画を「フック→展開→オチ→登録誘導」に分けた構成集（ページは structures.html）
- `analysis/*.md` …… 手本チャンネルの比較や、寄せてよい範囲などの分析

## 分析を頼むとき

このリポジトリに Issue を立て、札「分析依頼」を付ける。本文には、何を知りたいか・手本の URL・どのチャンネルで使うかを書く。
分析プロジェクトが毎日1回拾い、結果をここに置いて Issue に返事をして閉じる。

台本の文・映像・音は写さない。抜き出すのは型と構成だけ（policy_safe_vs_risky.md）。

## 視聴維持率の依頼（自分のショート）

自分の回の維持率データ（曲線・視聴した/スワイプの割合・秒つき台本、`analysis/raw/chizu_retention/`）が来たら、`analysis/shorts_retention_rules.md` に従う。
曲線を秒に直し、頭・途中の大きな落ち・最後2〜3秒の落ちを台本の秒と対応づけて理由を書く。同じファイルの「記録」に1行足し、新しくわかったことは「ルール」を直す。
改善チーム（司令塔側）がすでに見ている項目（話題の大きさ・台本の形・公開時間、Issue #14 の一覧）は繰り返さず、拾えていない点だけを足す。ラベル「司令塔へ」の Issue に新しい返事があれば、それも読む。
