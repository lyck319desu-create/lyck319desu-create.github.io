# WGM 作り直し：最近始めて数本で伸びた筋トレ系チャンネル20（長尺）

調査日：2026-10-21　／　公開情報のみ（yt-dlp の検索・動画一覧、RSS の概要欄）
依頼：WGM（Workout Gym Music）を筋トレ解説の長尺チャンネルに作り直す。ショートも含めてガラッと変える。手本は「最近始めて、数本で伸びたチャンネル」（再現性があるため）。20チャンネルほど出して、動画を人気順に並べ、伸びたものから型を取る。

- 各チャンネルの動画を人気順に並べた表：[wgm_benchmarks_popular.md](wgm_benchmarks_popular.md)
- 生データ：`analysis/raw/<ハンドル>/`、検索結果と約700チャンネルの開設日：`analysis/raw/search/`
- サムネ画像は公開リポジトリに載せず、Actions の成果物（thumbs）にある

## 0. 結論（先に）

1. **今のWGMは作り直すべき。** BGM長尺は147本あり、直近60本は1本7〜257回（過去最高でも1.2万回）。曲の並べ替えだけでは伸びていない。
2. **「若い男性向けの筋トレ解説」は顔出しの大手（ザ・きんにくTV、山澤礼明、まめたま など）が独占。** 新しく始めて数本で伸びた顔出しなしのチャンネルは、ほぼ全部が **「40〜70代 × 筋肉（筋トレ・たんぱく質）」** に集まっていた。
3. 再現性が一番高い手本は **シニア健康の答え合わせ**（9/23開設、15本・1か月で合計32万回、7本目で12.3万回）。ほぼ同じ作りで **毎日元気シニア**（8/10開設、2本目で17万回、11本目で86万回）、**からだのトリセツ**（12本目で52.5万回）、**キント道場**（1本目で6.8万回、16本目で17万回）が続く。
4. 型は3つに絞れる。WGMは **A「〇〇をやめる」型（10〜11分）** を主軸に、**B「〇〇のサイン10選」型** と **C「毎日〇〇を1年続けた体を検証」型** を混ぜるのがおすすめ。
5. 毎回1つ、手本にない要素を入れる（policy_safe_vs_risky.md）。WGMの独自要素の候補は「出典と自前の計算（キント道場の強み）を、シニア向けのやさしい語りに乗せる」こと。

## 1. 選び方

1. YouTube 検索を「今月」「今年」の公開・再生数順で、筋トレ／筋肉／ダイエット／シニア筋トレなど22通り実行し、出てきた約700チャンネルの開設日を RSS で調べた。
2. 2025年4月以降に開設、かつ筋トレ・筋肉が主題の動画で伸びたチャンネルを36個取り、全動画を投稿順と人気順に並べた。
3. **顔出し・本人の体が売りのチャンネルは外した**（再現できないため）：孤独のマッチョ（芸人の青木マッチョ）、夜職トレーニー、SHIU、しゅーる、さらだまっちょ、けい。
4. 英語・筋トレと関係の薄い動画で伸びたチャンネル（ASCEXIO、wu）も外した。

## 3. 数字から分かること

**(1) 「誰に向けるか」が一番効いている。** 20チャンネルのうち10万回を超えた動画の大半が、タイトルに「40代以降」「50代」「60代70代」「シニア」「高齢者」が入っている。若い男性向け（俺のマッスルアカデミア、筋肉雑学ずかん、ボーンくん）は1本当たって止まっている。

**(2) 同じ作りでも、題材で100倍の差が出る。**
- シニア健康の答え合わせ：同じ11分・同じ作りで「月水金の筋トレをやめる」12.3万回、「間食と1日5食をやめる」1,500回。筋トレの「回数・休み方・重さ」の話は伸び、食事や股関節の話は伸びていない。
- 毎日元気シニア：「たんぱく質・筋肉」の回（2本目17万、11本目86万、34本目24万）だけが飛び抜け、腎臓・目・血管の回は数百回。
- 漫画で学ぶシニアの人生CH・ズバッと知りたい雑学も、筋肉とたんぱく質の回が上位に入る。
→ **WGMは「筋肉」から外れないこと。** 健康全般に広げると外れ回が増える。

**(3) 当たり回が出るまでの本数は少ない。** 1本目〜7本目で10万回を出したのが6チャンネル（漫画シニア1本目、毎日元気シニア2本目、Immersive 3本目、Catalyst 3本目、ズバッと6本目、シニア健康の答え合わせ7本目）。最初の15本で当たりが出なければ題材を見直す目安になる。

**(4) 長さは5〜27分まで幅があり、長さそのものより題材。** 10〜13分（シニア健康の答え合わせ、ズバッと、漫画シニア）と20分超（毎日元気シニア、さっとん、老後破産）の両方で当たっている。

## 4. 型の分解（伸びた順に取るもの）

### A「〇〇をやめる」型（主軸に推奨）　手本：シニア健康の答え合わせ

- **タイトル**：`〈常識の行動〉をやめる｜〈年代〉の筋肉は〈数字〉で〈結果〉`
  例：月水金の筋トレをやめる｜60代70代の筋肉は72時間で育つ／3セット12回をやめる｜50代60代の筋肉のつけ方
- **構成**（12.3万回の回の章立て、約11分）
  - 0:00 結論を先に言う（中1日の休養が筋肉を削っている）
  - 0:41〜9:41 理由を4つ、1章2〜3分（筋肉72時間／腱は月単位／ホルモン／血管）
  - 9:41 まとめ
  - 10:16 最後に「お金のかからない習慣を1つ」…最後まで見る理由を冒頭で予告しておく
- **概要欄**：対象者の一言 → 何が分かるかの箇条書き → チャプター → 「AIで作成」の注記 → 免責
- **伸びた題材**：筋トレの頻度・回数・重さ・休み方の「常識」を否定するもの。食事・ストレッチの回は伸びていない。

### B「〇〇のサイン10選」型　手本：からだのトリセツ（52.5万）、今日からできる健康雑学（12.1万）、筋肉雑学ずかん（3.1万）

- **タイトル**：`【意外と知らない：ソレ筋肉がつき始めてるサイン10選】`／`筋トレの効果は見た目より先に「内側」から出る｜筋トレが効いている意外な7つのサイン`
- 3チャンネルが別々に同じ題材で当たっている＝**題材そのものに需要がある**。
- **構成**：見た目も体重も変わらない不安 → サインを1つずつ（研究の裏づけを一言）→ 最後の1つを一番強いもの（握力と寿命など）にする → 「いくつ当てはまったかコメントで数字で」
- 作りは VOICEVOX（青山龍星）＋いらすとや＋DOVA の BGM で十分に伸びている。

### C「毎日〇〇を1年続けた体を検証」型　手本：キント道場（17.2万・6.8万）、メタルくん（47.4万）

- **タイトル**：`50歳が毎日腕立て30回を1年続けた体を検証した`／`毎日30秒ぶら下がるだけで体はどうなるのか`／`夜に筋トレをするとどうなるのか`
- **構成**（キント道場、約7分）：問いかけ → 今の現在地（何回できるか、年代の基準）→ 検算1・2・3（研究と数字で自前に計算）→ 一番意外な数字 → 1年の設計図（やり方）→ 「今何回できるか数字でコメント」
- 概要欄に研究名と統計の出典を全部書く。数字が多いので AI 量産と見分けがつき、収益化の審査でも説明しやすい。

### 参考：D「画面に合わせて一緒に動く」型　手本：Immersive Warmup Japan（66.8万）

- 5分のゲーム風の運動動画。顔出しなしで「一緒にやる」を作れる唯一の例。ただし映像づくりの手間が大きく、筋トレ解説の主軸には向かない。ショートや月1の企画向け。

## 5. WGM への当てはめ（案）

- **誰に**：50〜70代の男性で「筋肉を落としたくない」人。タイトルに年代を必ず入れる。
- **長さ**：まず10〜12分（A・B型）。当たった題材は20分超の「完全版」にして出し直す（毎日元気シニア・さっとんの長さ）。
- **最初の10本の題材の案**（手本で伸びた題材の言い換え。台本・文はそのまま写さない）
  1. 毎日スクワットをやめる｜60代の脚は48時間休ませると太くなる（A）
  2. 軽い重さで回数を増やすのをやめる｜50代60代が筋力を落とさない重さの決め方（A）
  3. ソレ筋肉がつき始めてるサイン10選｜60代でも体重計に出ない変化（B）
  4. 60代が毎日腕立て10回を1年続けた体を研究で検算した（C）
  5. 筋トレ後すぐのプロテインをやめる｜60代70代の筋肉が応える時間（A）
  6. 筋肉が落ちている危ないサイン10選｜60代が見落とす小さな変化（B）
  7. 毎日かかと上げ50回を1年続けた脚を検算した（C）
  8. ウォーキングだけをやめる｜60代の脚の筋肉を守る組み合わせ（A）
  9. タンパク質20gの値段をスーパー15食品で比べた｜60代の筋肉を安く守る（C＋毎日元気シニアのランキング）
  10. 3セット10回をやめる｜60代70代の筋肉が一番育つ回数（A）
- **毎回の独自要素（手本にない1つ）**：キント道場式の「出典と自前の計算」を、シニア向けのやさしい語りと章立て（A型）に組み合わせる。具体的には毎回1つ「自分で計算した数字」を章に入れ、概要欄に計算式と出典を載せる。
- **ショート**：長尺の1章を60秒に切る（「サイン10選」の1つ、「〇〇をやめる」の結論だけ）。最後に長尺へ誘導する。
- **チャンネル名・サムネ**：今の名前（Workout Gym Music）は内容と合わなくなる。名前の変更は制作側（司令塔）とオーナーで決める。サムネはActionsの成果物（thumbs）で手本の現物を確認してから作る。

## 6. 注意

- 健康・医療に近い題材なので、概要欄の免責（医師に相談）と出典は必須。手本は全チャンネルが入れている。
- 手本の台本・文・図をそのまま使わない。取るのはタイトルの型・章立て・題材の選び方まで。
- 数字は2026-10-21の1回分。シニア健康の答え合わせ・キント道場・筋トレ仙人は開設1〜2か月なので、2026-11-04ごろにもう一度測る。
