## 何か

棒人間アニメの**台本と、動画生成AI（Google Flow の Gemini Omni Flash）に入れる指示文**を作る Claude/Codex 用の Skill。動画そのものは作らない。
流れ：テーマを渡す → 演出プラン（台本・場面・カメラ・音）→ 承認 → 10秒ごとの指示文 N 本 → Flow で生成 → CapCut などでつなぐ。

画風は5つ。今日の一歩（習慣・心理）に合うのは次の2つ。
- **スタイル1 白黒ミニマル**：白か黒の無地に線だけの棒人間、差し色は3色まで。「心理・自己管理・概念の解説」向けと書いてある。
- **スタイル4 ほっとする日常**：白い丸頭の棒人間＋フルカラーの背景。「習慣作り・日常の共感」向け。

**危ないのは入れ方。** README は「AIに『このSkillをインストールして：URL』と送る」入れ方を勧めている。これだと、そのとき最新の中身を中身を見ずに入れることになる。あとで誰かが中身を書き換えても気づけない（リポジトリは毎日更新されていて、外の人の PR も入っている）。

安全な入れ方：
1. 上の版（70199c8）に固定して、`skills/directing-stickman-videos/` のフォルダだけ写す（動画・テスト・scripts は写さない）。
2. 更新したくなったら、前の版との差分を読んでから入れる。
3. Flow はオーナーの Google アカウントで動き、有料の生成枠を使う。Skill が勝手に払うことはないが、作り直しが多いと枠を食う。

## 今日の一歩に使えるか

**使える所**
- 棒人間の「描き方の決まり文」（頭・線の太さ・腕と脚は2本ずつ、など）を毎回同じ文で入れる、という作り方。ここがキャラをぶれさせないための工夫の中心で、ベンチマークに寄せるときに役立つ。
- 「つかみ → 思い込みを崩す → 裏の仕組み → 本当の理由 → 締め」の5段の台本の型。

**気をつける所**
- ナレーションは英語前提。日本語の語りは今までどおり自分で入れて、生成するのは**声なしの映像だけ**にする（指示文の音声の部分は外す）。
- 1クリップが約10秒なので、8分の動画だと48本になる。本数が多いので、全部を AI 生成にするよりも、要の場面だけ生成して残りは静止画と動きでつなぐ方が現実的。
- 2025-07 以降、YouTube はテンプレートの作り回しを収益化の対象から外している。同じ Skill・同じ画風で量産すると、そう見なされやすい。1本ごとに手本にない要素を1つ足すルール（policy_safe_vs_risky.md）は続ける。
- 漫画風の絵なので、YouTube の「改変・合成コンテンツ」の申告は原則として要らない（申告の対象は本物らしく見える映像）。

**おすすめ**：入れるなら、上の安全な入れ方でスタイル1かスタイル4を試す。ただ、検証（kyou_no_ippo_reco_test.md）の手本はあくまでベンチマークの動画。この Skill の画風は、ベンチマークの見た目に近い場合だけ使う。
