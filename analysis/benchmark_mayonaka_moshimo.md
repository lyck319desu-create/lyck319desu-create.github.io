# 真夜中のもしも 分析 ＋ どぐう先生 長尺リニューアル案

調査日：2026-10-21　／　公開情報のみ（yt-dlp の動画一覧・RSS の概要欄・サムネの色。生データは `analysis/raw/mayonaka_moshimo/`）
きっかけ：オーナーのチャンネル整理（2026-10-21）「土偶先生→@mayonaka_moshimo をベンチマークとしてクオリティの高い長尺動画を出す方向：チャンネルのサムネイル等も全て変える」

## 0. 結論（先に読む所）

1. **当たっているのは「日本の昔の1日を、時刻ごとに再現する」1本の型だけ。** 5本中2本が当たり（29.8万・17.0万）、どちらも「〇〇年前の日本人の1日を再現したら、想像とまったく違った」。地球規模の「もしも」（人類消滅・富士山噴火）は1千回台。
2. この型は、どぐう先生が今やっている「昔の人はどうしてた？」（縄文〜昭和の暮らし・一次資料）と**題材がほぼ同じ**。ショートの延長として長尺に移しやすい。
3. 自分だけの要素は**どぐう先生（立体の粘土の土偶）を「案内役」として毎回出す**こと。相手は AI 映像＋男性の落ち着いた声。相手にも毎回出る案内役（頭が地球儀の背広の男）がいる（2026-10-21 に1秒1コマで確認、`style_clay_vs_photo_and_motion.md`）ので、どぐう先生はその役を自分のキャラで担う形になる。
4. 一番大きな問題は**作り方**。相手は1本13〜15分の大半を AI 動画（MiniMax）と AI 画（FLUX）で埋めている。今の studio（skia＋numpy の自作描画）で15分を毎回作るのは重い。制作側（司令塔）で決める必要がある（§6）。
5. 数字は**5本・開始12日**だけ。当たり2本はどちらも日本史なので「日本史が強い」とは言えるが、型の残りの部分（長さ・声・時刻の章立て）が効いたかは分けられない。2週間後（11/4ごろ）に見直す。

## 2. 当たり型の構成（14分前後）

2本の章立て（概要欄のチャプター）から共通の型を取り出した。文は写していない。

| 時間 | 段 | 中身 |
|---|---|---|
| 0:00〜0:40 | もしもの入口 | 「あなたが〇〇年前の日本にいたら」と**視聴者を主人公**にする。常識のイメージを1つ置く（「原始人は洞窟で暮らし…」「宵越しの銭は持たない」） |
| 0:40〜1:00 | 舞台の固定 | **日付と場所と人物まで決める**（「1826年10月14日、神田の大工のあなた」「静岡・愛鷹山のふもとの秋の1日」） |
| 1:00〜11:00 | 時刻ごとの章（7〜9章） | 章名は**「時刻＋意外な事実ひとこと」**。朝5時→夜11時と1日を進む。1章1〜2分。毎章に1つ、イメージをくつがえす数字か物証 |
| 途中 | 換算 | 昔のお金を**今の円に直す**（日当1万8000円、そば480円）。身近な物差しで比べる（「そば6杯分」） |
| 後半 | 線を引く | 「**ここから先はシミュレーション**」という章をはさみ、事実と推測の境目をはっきり見せる |
| 終盤 | 答え | 「**答え　〇〇だったのか**」の章で、冒頭の常識のイメージに白黒をつける |
| 最後 | 今につなぐ | 「200年後の神田で」のように、同じ場所の今に戻って終わる |

当たり2本の違い：
- 3万年前：答えの前に夜の場面（たき火・星空・噴火）で余韻。15分半。
- 江戸：家計の章（「1年で手元に残るのはいくら？」）がある。お金の話が多い方が伸びた（n=2なので参考）。

外れ3本との差：
- 外れは「消滅直後→1億年後」「噴火→2週間後」「水深10m→1万m」で、**進む軸が時刻ではなく経過時間か深さ**。主人公（あなた）も「当時の誰か」ではない。
- 外れの題材は地球・災害・科学で、日本の暮らしではない。

## 3. タイトルの型

当たり：
- `【3万年前の日本】原始人の1日を再現したら、想像とまったく違った`
- `200年前の日本人の1日を再現したら、想像とまったく違った`

型：**「（数字）年前の日本（人）」＋「の1日を再現したら」＋「、想像とまったく違った」**
- 数字は「年前」で書く（「江戸時代」「旧石器時代」とは書かない）。今からの距離で想像させる。
- 「再現したら」で、作り話ではなく記録から組み立てたことを言う。
- 「想像とまったく違った」で、見る前のイメージを裏切ると約束する。
- 【】は付けても付けなくても当たっている。

どぐう先生で使うとき：題名の文をそのまま写さない（後ろ半分が同じだと検索で並んだときに真似と見られやすい）。数字＋1日＋意外の3点だけ取る（§5 の案）。

## 4. サムネイルの型（見られた範囲）

この環境からはサムネの画像そのものを見られない（YouTube の画像サーバーに届かない）。代わりに Actions でサムネの**色・明るさの配置・文字読み取り**だけを取った（`analysis/raw/mayonaka_moshimo/thumbs_notes.json`）。

| 動画 | 主な色 | 明るさ | 文字読み取り |
|---|---|---|---|
| 江戸（当たり） | こげ茶・黒茶・灰茶・生成り | 左上が明るく、下が暗い | 大きな文字は読み取れず |
| 3万年前（当たり） | 茶・黒茶・砂色・赤茶 | 全体に暗め、右上だけ明るい | 大きな文字は読み取れず |
| 深海（未判定） | 紺・黒・青緑 | 上が明るく下が真っ黒 | 「水深1万mまで沈んだら」が読めた |

- 当たり2本は**暗い土色（茶・黒）の写真風の場面**。光源が画面の上か横に1つある「夜・朝の室内」の明るさの配り方。
- 文字の読み取りが当たり2本でだけ失敗しているので、**文字が少ないか、場面に溶けこむ書き方**の可能性がある。ここは推測。オーナーが YouTube で2本のサムネを見て確かめてほしい（10秒で済む）。

## 5. どぐう先生リニューアル案

### 5-1. 写す所と、変える所

| | 写す（型） | 変える（自分だけの要素） |
|---|---|---|
| 題材 | 日本の昔の1日（縄文・江戸・昭和など） | 時代は縄文〜昭和で回す。江戸ばかりにしない |
| 構成 | 入口→舞台の固定→時刻の章→換算→「ここから推測」→答え→今に戻る | **どぐう先生が案内役**として章の頭と答えで出る。「先生のひとこと」の段を毎回1つ |
| 題名 | 数字＋1日＋イメージを裏切る | 後ろ半分の言い回しを変える |
| 信頼 | 概要欄にチャプター・「気をつけたこと」・出典・AI 使用の明記 | 今の「一次資料で確かめる」決まりをそのまま使う |
| 映像 | — | 粘土の立体・油絵の差し込み（今の studio の強み）。AI 映像は使うなら明記 |
| 声 | 落ち着いた声、ゆっくり | 春日部つむぎのままでよいか要判断（相手は男性の低い声。夜に聞く長尺にはつむぎは明るすぎる可能性） |

YouTube の「繰り返しの多いコンテンツ」対策（`policy_safe_vs_risky.md`）：毎回、相手にない要素を1つ入れる。どぐう先生が出ること自体がチャンネル全体の差になるが、それとは別に**1本ごとに変える物**（時代・主人公の職業・山場の見せ方）を今の「毎回変えるもの」の表で続ける。

### 5-2. 最初の3本の題材案（当たり型に近い順）

| 案 | 舞台 | 主人公 | 題名の例（言い回しは自作） |
|---|---|---|---|
| 1 | 約5000年前の縄文（三内丸山など） | 縄文の村の子ども | 5000年前の日本で1日暮らしてみたら、イメージが全部ひっくり返った |
| 2 | 約100年前の昭和初め（東京の下町） | 路面電車の車掌 | 100年前の東京人の1日を時間ごとに再現｜給料・ごはん・お風呂の値段 |
| 3 | 約1300年前の奈良の都 | 役人（下級の官人） | 1300年前の公務員の1日を再現したら、朝が早すぎた |

- 縄文と昭和はどぐう先生のショートですでに調べた資料（ep02 火おこし・ep03 氷冷蔵庫）が使える。
- 江戸の1日は相手が当てたばかりで、同じ題材は真似と見られやすい。後回しにする。

### 5-3. チャンネルの見た目を全部変える案

名前・ハンドルは 10/5 と 10/8 に変えた（14日で2回まで）。制作側の記録では **10/19 以降はまた変えられる**（今は変更できるはず）。

| 項目 | 今 | 案 |
|---|---|---|
| 名前 | どぐう先生 | 案A「どぐう先生の時間旅行」／案B「むかしの1日」／案C「どぐう先生」のまま（見た目だけ変える） |
| 説明 | ショートの説明（歯ブラシがない時代…） | 「〇〇年前の日本で、ふつうの人はどんな1日を送っていたのか。土偶のどぐう先生が、一次資料と研究をもとに時間ごとに再現する長尺のチャンネル」＋事実と推測を分ける・出典は概要欄・AI 使用の明記 |
| アイコン | 粘土の土偶の顔のアップ（明るい） | どぐう先生の顔は残し、背景を夜の暗い土色にする（サムネと色をそろえる） |
| バナー | 土偶・名前・ひとこと・時代の札 | 横に「縄文→奈良→江戸→昭和」の時間の帯。夜の色。どぐう先生は小さく案内役の位置 |

| 動画の長さ | 45〜55秒 | 12〜15分 |

今のショート5本：消さない。長尺の章を切り出したショートを、長尺の宣伝として続けてもよい（ショートを続けるかは制作側の判断）。

## 6. 制作側（司令塔）で決めること

1. **映像の作り方**：15分を今の自作描画だけで作るか、AI 映像・AI 画を混ぜるか（混ぜるなら概要欄と画面で明記。相手は MiniMax と FLUX）。
2. **声**：春日部つむぎのままか、落ち着いた声に変えるか（相手は AivisSpeech の男性の声）。
3. **名前を変えるか**：§5-3 の案A／B／C。
4. **江戸の割合の決まり**（江戸は全体の半分以下）：長尺でも続けるか。
5. 予約タスク dogu-daily（偶数日 12:10、ショート1本）をどう変えるか。
