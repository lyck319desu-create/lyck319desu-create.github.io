## 検証のやり方

**何を変えないか**：手本の型（上の表）を全本で固定する。変えるのは題材だけ。
**題材**：手本の再生数上位から選ぶ。「需要がある題材」で試せば、乗らなかったときに題材のせいにできない。
**本数**：5本。1〜2本はブレが大きすぎて判定できない。5本出して、何本が乗ったかで見る。
**間隔**：2〜3日に1本、同じ曜日・時刻に固定（例 18:00）。約2週間で5本そろう。
**期間中にやらないこと**：
- 公開後72時間は題名・サムネを手で変えない（変えると数字がどちらのせいか分からない）。サムネを比べたいときは Studio の「テストと比較」（最大3枚）を最初から使う。
- 外部（X など）への貼り付けは控える。外から来た人の数字が混ざると、おすすめの判定がにごる。
- ショートで告知しない（入口が混ざるため。ショートの検証は別にやる）。

## どの数字で判定するか

Studio → 動画ごとのアナリティクス →「リーチ」タブ。各動画で **48時間・7日・28日** の3回読む。

| 数字 | 場所 | 意味 |
|---|---|---|
| インプレッション数 | リーチ | YouTube が何回見せたか |
| インプレッションのクリック率 | リーチ | 見せたうち何%押されたか |
| トラフィックソース：「ブラウジング機能」 | リーチ | ホーム・登録チャンネル欄＝おすすめ |
| トラフィックソース：「関連動画」 | リーチ | 他人の動画の横・下＝おすすめ |
| 平均視聴時間・平均再生率 | エンゲージメント | 見続けられたか |
| 冒頭30秒の維持率 | エンゲージメント（維持率のグラフ） | 入口で離れていないか |

「おすすめ」＝ブラウジング機能＋関連動画、の合計で見る。

## 合格ライン（1本ごと、公開7日）

**おすすめに乗った**（次の3つ全部）：
1. ブラウジング機能＋関連動画のインプレッションが 7日で **1,000回以上**
2. 再生のうち、ブラウジング機能＋関連動画から来た割合が **50%以上**
3. 3日目以降もインプレッションが増え続けている（初日で止まっていない）

**中身が足りている**（乗るための条件）：
- クリック率 **4%以上**（2%未満は入口の問題）
- 平均再生率 **35%以上**（8分なら約2分50秒）、冒頭30秒の維持率 **65%以上**

数字は小さなチャンネルの目安（YouTube 公式は「半分のチャンネルのクリック率は2〜10%」）。手本の数字は外から見えないので、手本と同じ型でこの線を越えるかで見る。

**全体の判定（5本そろったら）**：
- 5本中2本以上が「乗った」→ 型は効く。この型で続ける。
- 乗った0〜1本 → 下の切り分けで原因を決めてから、1つだけ変えて次の5本。

## 乗らなかったときの切り分け

| 見え方 | 原因の見立て | 次に変える1つ |
|---|---|---|
| インプレッションが少ない（7日で300未満）、クリック率はふつう | YouTube がチャンネルの視聴者像をつかめていない（前の動画と客がずれている） | 古い動画の非公開を検討、題材を手本にさらに寄せる |
| インプレッションは出るがクリック率2%未満 | サムネ・題名 | サムネを手本にさらに寄せる（「テストと比較」） |
| クリック率は出るが冒頭30秒で半分以上離れる | 冒頭 | 冒頭30秒を手本の作りに合わせる |
| 全部ふつうなのに広がらない | 本数が足りない | そのまま5本追加して待つ |
