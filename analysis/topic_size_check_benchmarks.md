# 話題の大きさの基準を手本チャンネルで確かめる（Issue #3）

調査日：2026-10-20　／　公開されている再生数（yt-dlp で一覧を取得）。題名と数字だけを使い、台本は見ていません。
元データ：ブランチ `claude/project-thread-visgfh` の `analysis/raw/`（noah_lostworld・地理でいこーよ・Mini Map のショート全件）

## 結論

**「話題の大きさで差が出る」は、3つの手本チャンネルすべてで同じでした。** 同じ型（noah の「3選」、地理でいこーよの「なぜ〜のか」）でも、上位と下位を分けているのは題材の大きさです。
ただし基準のうち **3（大きな数字）は直したほうがよい**、また **「大きさ」には地図の広さのほかに「関わる人の多さ（もし起きたら困る人の数）」がある**、の2点がわかりました。

## 比べ方

- 各チャンネルのショートを再生数順に並べ、上位20%と下位20%の題名を比べた。公開から日が浅い最新10本は除外。
- 題名を「日本」「戦争・もし」「数字入り」などの言葉で分け、入っている回と入っていない回の再生数の中央値を比べた（言葉での分け方は大まかです）。

| チャンネル | 本数 | 全体の中央値 | 「日本」入りの中央値 | 上位20%に「日本」 | 下位20%に「日本」 |
|---|---|---|---|---|---|
| 地理でいこーよ | 436 | 38.7万 | 46.5万 | 10本 | 3本 |
| noah | 165 | 18.5万 | 19.2万 | 14本 | 6本 |

## 上位と下位の違い（型だけ）

**上位に多いもの**
- 日本全体、または日本人なら誰でも知っている場所どうしの関係（日本列島の海岸線、四国と九州の間、日本と南米、対馬）
- 国どうしの「もし戦争になったら」（Mini Map は上位113本中54本がこの型、下位は6本だけ。中央値43万 対 17万）
- 地球全体・人類全体のスケール（noah の「地球を掘ったら」「昔の日本人の警告」が1位・2位）
- 「唯一」「最も」と言い切れる一点（世界で唯一〜の国、地球で最も孤立した島）

**下位に多いもの**
- 1つの州・県・町の話（アメリカの州の借金、静岡・岡山がいい、特定のビーチ）
- ランキングや統計の数字（英語力の高い国5つ、CO2排出の多い国、睡眠時間の長い国）
- 細かい記録や小ネタ（noah の江戸の物価、昔の料理本、裁判、動物の寝方）。型は上位と同じ「3選」なのに1〜5万回
- 有名な場所でも、細かい決まりごとの話（noah の富士山の県境 3.3万）
- 「もし」でも、影響が一地域で終わる話（地理でいこーよの「もしスコットランドが独立したら」「もしロシアが民主化したら」は下位）

## 基準に足すこと・直すこと

1. **全国の人が地図で思い浮かべられる** → そのまま。富士山の例のとおり、場所が有名でも話が細かいと伸びないので「場所」と「話」の両方が大きいこと。
2. **日本全体か大きな地域** → 「日本全体、**または誰でも知っている2つの場所の関係**（四国と九州、本州と北海道など）」に広げる。1か所だけの話は下位に多い。
3. **大きな数字や「0」「1本」の言い切り** → **直す**。題名に数字が入った回は、地理でいこーよ・Mini Map ではむしろ中央値が低かった（35万 対 39万、13万 対 24万）。効くのは「0」「唯一」「最も」の言い切りと、数字そのものが異常なとき（例：1,470万匹）だけ。統計やランキングの数字は効かない。
4. **（足す）もし起きたら、困る人が多い話** → 「もし〜なかったら」型が地図の理由で伸びなかったのは、影響が小さく見えたからと考えられる（推定）。もし型を使うなら「もし中央構造線が動いたら関西と四国はどうなる」のように、日本の大勢の暮らしに返すときだけにする。

## 手本に無い要素を1つ足す提案

**回をまたいで1枚の日本地図を育てる。** 毎回の最後に、その回で出てきた線や場所を同じ日本地図に書き足し、それまでの回のぶんも薄く表示する。3つの手本はどれも1本ごとに完結していて、この「積み上がる地図」は無い。続けて見る理由と、前の回へ戻る理由が作れる（テンプレの繰り返しに見えにくくする対策にもなる）。

## 注意

- 再生数は今の合計なので、古い回ほど有利。最新10本は除いたが、公開時期の差は残る。
- 一部の題名は英語に自動翻訳された形で取れたため、言葉での分け方は大まかです。傾向を見るための数字として使ってください。
