## やり方

有料の動画生成（Google Flow）は使わない。Skill の**決まりだけ**を借りて、絵は Python（Pillow）で描き、ffmpeg で動かす。

| Skill から借りるもの | どう使うか |
|---|---|
| スタイル1の描き方の決まり（中が白い丸い頭、線の太さは一定、腕と脚は2本ずつ、表情は線だけ、差し色は3色まで） | `stickman.py` の `figure()` に決め打ちしてある。全部の場面で同じ関数で描くので、キャラがぶれない |
| 5段の台本（つかみ → 思い込みを崩す → 裏の仕組み → 本当の理由 → 締め） | 8分の台本の章立てにする。語りは日本語で、今までどおり自分の声（VOICEVOX など） |
| 2〜3秒ごとに絵を変える、キャラを止めない | ポーズの間を補って動かす（関節の角度を少しずつ変えて、30fps で書き出す） |
| 絵の中に文字を入れない、字幕は後で | 字幕は ffmpeg か編集ソフトで後から入れる |

足した自分の要素：頭の上の**緑の芽**（今日の一歩の印）。差し色は 赤＝誘惑、青＝集中、緑＝成長 の3色。
