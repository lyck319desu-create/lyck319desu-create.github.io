# すけマッチョ：長尺の手本探し（2026-10-23）

依頼：オーナー（2026-10-23）「しっくりこない。ベンチマークの調査をもっとして分析に力を入れる方向に一旦戻りたい。長尺メインでやりたい」。

- データ：GitHub Actions（yt-dlp）で取得。検索 18件（筋トレ雑学・サイン・〜を続けるとどうなる 等）と既存の検索約70件、検索に出た約2,000チャンネルの開設日と直近15本、候補 36チャンネルの全動画一覧（`analysis/raw/<チャンネル>/list.json`）。
- 再生数は yt-dlp の概数。題名は英訳で入ることがあるので、RSS（直近15本）の日本語の題名で確かめた。
- 「何本目」は長尺だけを古い順に数えた番号。

## 1. 結論

1. **長尺の筋トレで、新しく始めて伸びているのは「筋トレ雑学の10選」型。** 8〜15分で、「〇〇な人は△△よりもコレしてる10選」「筋肉がつき始めてるサイン10選」のように、1本に10個の答えを並べる。声は VOICEVOX（青山龍星）、絵はいらすとや風の白背景。
2. **一番の手本候補は「雑学ネットフリクス」。** 長尺 142本の中央値が 5.5万回（10万回以上が 52本、100万回以上が 4本）。1本目から 15.9万回、3本目は 61.8万回。最近の15本も中央値 3.3万回で、9月に 88.6万回が出ている。ショートは0本で、長尺だけで伸びている。
3. **今のホワイトマン路線は長尺に向かない。** ホワイトマンの長尺のヒットは 2〜3分の動画。メタルくんも 2分台。「長尺メイン」にするなら、型そのものを替える必要がある。
4. **灰色のマッチョ人物の型（マッチョラボ・ホワイトマン）は、8分以上の長尺では弱い。** マッチョラボ（2026-03 開始、8分の「〜を続けるとどうなるのか」）は 23本で中央値 1,000回。
5. 決めてほしいこと（下の 6 節）：手本を雑学ネットフリクス型にするか、絵をいらすとや風にするか、すけマッチョの人物を残すか、WGM との分け方。

## 3. 伸びている長尺の共通点

| 項目 | 中身 |
|---|---|
| 題名 | 「〇〇な人は、△△よりもコレしてる10選」「〜のサイン10選」「〜な人の意外な特徴10選」「〜を続けると体に起こる10の変化」。比べる相手（ランニング・腹筋・プロテイン）を出し、答えは伏せる |
| 長さ | 8〜15分。10個を1個あたり約70〜80秒 |
| 構成（雑学ネットフリクスの章立て） | 0:00 導入（約30秒）→ ①〜⑩（各70〜80秒）→ まとめ（約1分）。全部の動画で章の時刻が説明欄にある |
| 声 | VOICEVOX 青山龍星（雑学ネットフリクス・からだのトリセツの両方。無料） |
| 絵 | いらすとや風の白背景。人物は描き込みの少ない丸い顔。サムネは上下に黒の極太の縁取り文字、真ん中に人物の絵、赤い矢印で「前→後」 |
| サムネの文字 | 上に「体脂肪減ってく人は」、下に「運動よりもコレしてる」。2行で、答えは書かない |
| 収益 | 説明欄に食品・プロテインの楽天・Amazon・iHerb のリンク（アフィリエイト） |
| 視聴者 | 30〜50代の「痩せたい・筋肉をつけたい」人。50代向けの題名（「実は50代でお腹痩せする人は…」88.6万）も強い |

逆に伸びていないのは、次の2つ。
- 1つの問い（「〜を続けるとどうなるのか」）で 8分もたせる型（マッチョラボ・シンカマン）。
- 同じ型でも、題材が細かすぎる回（空気椅子と血圧・食後スクワットなど、数百回）。

## 4. サムネの見た目（手本候補 30本を見た結果）

- 雑学ネットフリクス・からだのトリセツ・筋肉に効く雑学・健康と筋トレの雑学は、4つとも白背景にいらすとや風の絵、黒の極太文字。
- ホワイトマン（灰色の背景＋白い無個性の人物）は 2〜3分の動画のサムネ。
- マッチョラボ（黄色の背景＋マネキン風の灰色マッチョ）は、絵の質が高いのに再生は少ない。
- 暗い背景＋写真のシルエット（筋トレ科学ラボ）は、数万回止まり。

→ 長尺のこのジャンルで勝っているのは「絵のうまさ」ではなく、「題名の問い」と「10個の中身」。

## 5. すけマッチョに当てはめると

| 項目 | 案 |
|---|---|
| 型 | 「〇〇な人は、△△よりもコレしてる10選」を軸に、「サイン10選」「NG習慣10選」を回す |
| 長さ | 12〜14分（導入30秒＋10個×70秒＋まとめ1分） |
| 声 | VOICEVOX（無料）。手本と同じ青山龍星にするか、別の声にするか（6節） |
| 絵 | A案：いらすとや風の白背景（手本に一番近い）／B案：白背景に、すけマッチョの人物を差し込む（チャンネルの顔を残す） |
| 1本に1つの独自要素 | 「数字の検算カード」（例：1回70kcal×週3回＝月840kcal）か、出典の札。手本には無い |
| 本数 | 雑学ネットフリクスは月6〜8本。最初の1か月は週2本で 8本を目安にする |
| 題材の選び方 | 手本の上位（体脂肪・お腹・増量・筋肉が早くつく人）から選び、比べる相手と切り口を変える。題名の文はそのまま使わない |

## 6. 決めてほしいこと

1. **手本**：雑学ネットフリクス型（10選・12〜14分）にするか（推奨）。今のホワイトマン型（2〜3分）を続けるか。キント道場型（検証・7分）にするか。
2. **絵**：いらすとや風にするか、すけマッチョの人物を残すか。いらすとやは無料で、商用利用もできる。ただし「1つの作品に使うのは20点まで」という決まりがあるので、1本の動画あたりの点数を数える必要がある（規約は使う前にもう一度確認する）。
3. **WGM との分け方**：WGM も筋トレの長尺に変える予定。同じ「10選」型を2つのチャンネルでやると、題材がぶつかる。分け方の案は、すけマッチョ＝10選の雑学、WGM＝一緒にやる・メニュー。
4. **声**：手本と同じ青山龍星にするか、別の声にするか。

## 7. 気をつけること

- 雑学ネットフリクスの題名・章の中身をそのまま写さない。比べる相手・切り口・順番を変え、根拠の出典を自分で調べる。
- 同じ型の量産は、2025-07 からの「繰り返しの多いコンテンツ」の収益化審査に引っかかりうる（policy_safe_vs_risky.md）。1本ごとに独自要素を1つ入れる。
- 健康の話なので、医学的な助言ではない旨を説明欄に入れる。
- 再生数は題材と時期で大きく変わる。この型で必ず伸びるとは言えない（雑学ネットフリクスでも、数千回の回がある）。
