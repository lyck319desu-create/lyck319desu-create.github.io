## 1. 結論

1. **キント道場は、確実さの点では下位だった。** 直近15本のうち1万回を超えたのは3本だけ（最小 360回、中央値 3,693回）。17.2万回の1本に引っ張られていた。手本から外すのが良い。
2. **一番「確実」なのは「論文で解決 ~筋肉と栄養を科学する~」。** 直近15本が **15本とも 1.75万回以上**（中央値 4.9万回、最大 11.3万回）。2日に1本（月18本）出していて、どの回も外していない。直近30本で見ても、全部 1万回以上・中央値 4.85万回。
3. **人が映らず、すけマッチョでも作れる形。** サムネも本編も、CG の筋肉の絵＋極太の文字で、顔出しがない。出典の論文を説明欄に10本前後並べる作り。すけマッチョが元々やっていた「出典つきの図解」と、方向が同じ。
4. **数字の大きさを優先するなら「筋トレの科学【理学療法士リョウ】」。** 直近15本の中央値 9.7万回、15本中14本が1万回超。18〜31分で月8本。こちらも顔出しはほぼない（体の写真が中心）。
5. **ただし、この2つはどちらも開設が古い**（論文で解決 2019年11月、筋トレの科学 2020年12月）。「最近始めて数本で伸びた」という好みとは外れる。今回調べた範囲では、**最近始めた筋トレの長尺で、全部の回が安定して伸びているチャンネルは見つからなかった**。新しいチャンネルは、当たり外れが大きい。

## 4. すけマッチョに当てはめるなら

| 項目 | 案 |
|---|---|
| 型 | 論文で解説。1本につき「最新研究＋数字」を軸に、すけマッチョが図解する |
| 長さ | 15〜20分（手本は22分。最初は作れる長さから） |
| ペース | 週2本（手本の2日に1本は、今の体制では無理がある） |
| 題名 | 「【2026年最新研究】〜」「【9割が知らない】〜」＋ 具体的な数字 |
| サムネ | 暗い背景＋すけマッチョ＋極太の文字＋数字の札。顔出しなしで同じ形にできる |
| 中身 | PubMed などの論文を自分で引いて、説明欄に出典を並べる |
| 手本にない要素 | すけマッチョの「検算カード」（式を1枚の絵で見せる）。手本は文字で読むだけ |

ここで気になるのは、1本に論文10本を読む手間。週2本なら、1本あたり2〜3日かけられる。最初の2本を作ってみて、続けられるペースを決めるのが良い。

## 5. 気をつけること

- 論文で解決の題名・説明欄・図はそのまま使わない。論文は自分で引き直し、要約も自分の言葉にする。
- 研究の結果を誇張しない（「1.3倍」のような数字は、条件つきであることを本編で言う）。
- 健康の話なので、医学的な助言ではない旨を説明欄に入れる。
- この2チャンネルは開設が古く、積み上げた登録者の力もある。同じ型で作っても、最初の数本は同じ数字にはならない。
- 今回の「確実さ」は直近15本だけで見ている。登録者数は取得できていない。
