## 2. タイトルの型

骨組み：**［具体的な数字つきの事実］は、なぜ［常識とずれる結果］のか？［どう解くか／何で見るか］【正式な用語】**

3本目は「なぜ琵琶湖は400万年前、三重県にあったのか？…を標高データで追う【古琵琶湖】」で、3本とも同じ骨組み。「標高データで〜」の一ひねりは3本中2本に入り、チャンネルの決まり文句になっている（＝寄せる側は使わない方がよい）。

| 部品 | 1本目（縄文海進） | 2本目（フォッサマグナ） | 働き |
|---|---|---|---|
| 数字 | 7000年前 / 60km | 深さ6000m | 冒頭で規模を見せてクリックの理由を作る |
| なぜ〜のか？ | なぜ…広がっていたのか？ | なぜ地図に見えないのか？ | 答えを言わない問い。全角「？」 |
| 一ひねり | 海面上昇だけではない理由 | 標高データで見る日本列島の割れ目 | 「よくある説明では足りない」「データで確かめる」という約束 |
| 【用語】 | 【縄文海進】 | 【フォッサマグナと中央構造線】 | 末尾に検索語。教科書の用語そのまま |

細かい特徴
- 文字数は 47〜57字。読点「、」で数字の主語と問いを区切る。
- 問いは「見えないのか」「広がっていたのか」のように、**常識と逆の状態**を問う。
- 煽り語（衝撃・ヤバい・9割が知らない）は使っていない。落ち着いた学術寄りの口調で、それがチャンネルの信頼感になっている。
- タイトルとサムネの文言は**わざと別**。タイトル＝数字と理屈、サムネ＝一目で分かる具体物の問い。

共通の文法
1. 地図が画面いっぱい。人の顔・ロゴ・チャンネル名なし。
2. 文字は左寄せ・左側に集め、地図の見どころは右側。
3. 「なぜ」から始まる短い問い。答えは書かない。
4. 白の極太明朝＋1語だけ金色。
5. 赤橙の丸か矢印で「ここ」を1か所だけ指す。
6. 1枚に色は 背景の地図色＋白＋金＋赤橙 の4つまで。

伸びた方の違い：誰でも知っている目印（富士山）が写っていて、丸で囲まれていた。陰影図で山の凹凸がはっきり見えた。

## 4. 地図の理由 用：寄せる所と変える所

方針（policy_safe_vs_risky.md）：型・フック・構成は借りる。サムネ画像そのものの複製と、文言の完全一致はしない。2025-07以降はテンプレ的な反復チャンネルが収益化停止の対象なので、毎回手本にない要素を一つ足す。

| 寄せる（型なのでOK） | 変える（そっくりにしない） |
|---|---|
| タイトルの骨組み「数字＋なぜ〜のか？＋一ひねり＋【用語】」 | 「〜で見る〜」「〜だけではない理由」など手本と同じ言い回しの連発 |
| サムネの文法（地図全面・左に問い・1語差し色・赤い丸/矢印） | 金色とまったく同じ差し色・同じ明朝体・同じ配置の組み合わせ。**差し色か字体のどちらかは自分の色にする**（例：差し色を水色 #4FD1E8 に、または字体を極太ゴシックに） |
| 国土地理院の標高データの陰影図を背景に使う（公開データ。出典表記は必須） | 手本のサムネ画像や地図画像の流用・トレース |
| 概要欄の 要約→目次→参考文献→注釈→データ出典 の並び | 手本の文の書き換え程度の流用 |

毎回足す「手本にない要素」の候補（1本に1つ）
- サムネ右上に**数字バッジ**（例「+3m」「6m」）を置く
- 「昔／今」を左右に割った**2枚比べ**の地図
- 自分で歩いた**現地写真**を地図に1枚重ねる
- 動画の中で**視聴者が自分の住所で試せる**問い（「あなたの家は海の底だった？」）

## 6. サムネ設計（1280×720）

```
┌────────────────────────────────────────┐
│ 左45%：暗いグラデ（#07141D→透明）        │
│  なぜ［関東］だけ        ← 1行目 白 極太  │
│  広い？                  ← 2行目          │
│                              ◯ ← 赤橙丸   │
│                    背景：陰影図 全面        │
│                                 [数字]←足す要素│
└────────────────────────────────────────┘
```

- 文字：2〜3行、計8〜15字。1文字の高さ 130〜170px。白、黒の影（ぼかし8px・不透明70%）。
- 差し色：1語だけ。手本の金色と別にするなら水色 #4FD1E8 か、金色を使うなら字体を極太ゴシック（Noto Sans JP Black など）にする。
- 印：赤橙 #F05A3C の丸（線12px＋黒縁4px）か矢印を1か所だけ。
- 背景：国土地理院 標高タイルの陰影図（出典「国土地理院」を概要欄に）か、平らな都道府県地図＋紺の海。
- 置かないもの：顔、ロゴ、チャンネル名、3色以上の差し色。
