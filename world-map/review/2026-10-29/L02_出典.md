手本：RealLifeLore「Why 80% of Americans Live East of This Line」(wwJABxjcvUc)・「Why 70% of Spain is Empty」(pL8XPZp4-5c)。字幕からは流れの順番だけを取り、言い回しは使っていない。

| 手本の型 | 手本でのやり方（要約） | L02 での当て方 | 行 |
|---|---|---|---|
| 0秒で人口分布の地図を指す | 人の住む場所の地図から入る | 「この地図は、中国の人が住む場所です」 | 1 |
| 30秒以内にまっすぐな線と大きな問い | 境目の直線→割合→「なぜ」 | 線を引く→94%／6%→名乗り→問い | 3〜7 |
| 割合の数字をもう一段くわしく | 東西の割合・人数・密度 | 1933年36/96、今の43/57、1953〜2010年、密度22倍 | 17〜25 |
| 線の両はし・線の上の町 | 線ぞいの町を名指し | 北のはし黒河（旧 瑷琿）、南のはし騰衝。東の北京・上海・広州、西のウルムチ・ラサ | 11〜16, 27〜30 |

## 4. 確かめられず外した事実

| 外したもの | 理由 |
|---|---|
| 1935年の人数（東南 約4億4千万人・西北 約1,800万人） | 胡煥庸の原文（地理学報 1935年 第2巻第2期）の本文を直接読めず、二次資料の引用しか見つからなかった |
| 胡煥庸の点の地図の作り方（1点＝2万人、点が2万個あまり） | 同上（二次資料のみ） |
| 胡煥庸の生まれ年・出身（1901年・宜興）や当時の所属（中央大学） | 一次資料で確かめられなかった。人物の紹介は「地理学者」だけにした |
| 1982年 94.2%・1990年などの他の年の割合 | 陳2016 表1にない年はニュース記事の数字しかなかった |
| 「雨の影」（ヒマラヤが南からの湿った風をさえぎる仕組み） | 一次資料で言い切る文が見つからなかった。台本は「南東で多く、北西へ減る」（西藏概況）と「季節風のはし」（康2015）だけにした |
| 中国の「3つの階段」（地形の段） | 一次資料を当たる時間がなく、入れなかった |
| 黒河・騰衝の人口、国境線の長さ、騰衝の火山・温泉 | 市の政府の一次資料が見つからなかった（百科・旅行サイトのみ） |
| 線の上にある町の名前（蘭州・成都・包頭など、線のどちら側か） | 線は地図の図法で位置がずれ、線の近くの町は資料ごとに側が変わる。だいぶ離れた町（北京・上海・広州／ウルムチ・ラサ）だけ名指しした |
| チベットの面積（120万km²あまり）とそこから出す密度 | 新華社の報道で見つかったが、政府の一次資料のページは確かめられなかった |
| 西部大開発の「国の面積の71.4%」 | 資料ごとに71.4〜71.6%と違い、政府の一次資料で確かめられなかった |
| 1950〜70年代に新疆へ移った人の数（上海の若者など） | 白書は「大勢が移った」とだけ書き、数を出していない |
| 400ミリ線が近年北へ動いている、という話 | 研究によって「動いている／長い傾向はない」と分かれる |
| 中国全体の年平均降水量 | 気象局の気候公報の数値まで確かめられなかった（順位だけ） |
| 東の穀倉の具体の数字（米・麦の産地の割合を線で分けたもの） | 胡煥庸線の東西で分けた一次資料の数字が見つからなかった。「64%の耕地が秦嶺・淮河より北」は線と関係がないので使わなかった |

## 5. 声・字幕のメモ

- 読み付き：胡煥庸（こかんよう）・黒河（こくが）・騰衝（とうしょう）・瑷琿（あいぐん）・愛輝（あいき）・黒竜江省・雲南省・新疆・青海省・広東省・広州・崑崙・天山・地理学報・前漢・新疆生産建設兵団・兵団・李克強・四川・重慶・青稞（チンコー）
- 字幕の1句は15字以内（多くは14字以内）。
- 1935年の数字は「1933年ごろの人口の数字」と言う（陳2016 表1 が1933年の行になっているため）。題名・短い版の「1935年 96対4」とは矛盾しない（1935年に出した論文の数字）。
- 2020年の93.5は、2010年までの表と線の引き方が違う（131行目で断っている）。冒頭の「およそ94%」は短い版と同じ。
