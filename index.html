YouTube 投稿管理ツール（個人用）

このツールは、運営者が自分の YouTube チャンネルに動画を投稿・管理するために使う個人用のツールです。一般向けのサービスではなく、運営者以外のユーザーは利用しません。

YouTube Data API と YouTube Analytics API を使い、運営者自身のチャンネルについて次のことを行います。

  • 動画のアップロードと公開予約
  • 動画のタイトル・説明欄・サムネイルの更新
  • 再生回数などの統計の確認

プライバシーポリシー

This is a personal tool used only by its owner to upload and manage videos on the owner's own YouTube channels. It is not offered to other users. Privacy Policy
