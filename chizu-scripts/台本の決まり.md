# 地図の理由 長尺 台本の決まり（2026-11-08）

チャンネル「地図の理由」：日本の地図に残る「なぜ」を、立体地図で解き明かす。声は音読さん Flora（女性ナレーション、速さ0.9 ≒ 1分に約400字）。

## 長さ・形
- 約13〜14分＝本文 約5,000〜5,600字（かなに直す前）。1行＝1文、短く（40字以内が目安）。全部で 120〜140 行ほど。
- やさしい日本語。専門用語は出したらすぐ言いかえる。数字は大事なものだけ。
- 冒頭（1分以内）の型（1分後に7割残った型）：
  1. 「地図のここを見てください。」で場所を見せる
  2. 「ここだけ、ちがいます。」で異常を見せる
  3. 「なぜでしょうか。」＋題名と同じ問い
  4. 「先に、結論を言います。」＋結論を1〜2文
- 本文：結論→なぜ→説明。章（見出し）は4〜6個。
- 「見せる約束」の場面を必ず1つ入れ、題名 A はそれを約束する（例：海の水を抜いて見てみた、地面をはがして見てみた、〇〇万年前に戻してみた）。その場面は動画の中盤〜後半にしっかり時間をとる。
- フリー素材の実写を 5〜8 か所（Pexels / Pixabay で探せる言葉を書く。例：「Tokyo skyline aerial」）。
- マイナスの前置き（「先に断っておくと」等）で題名・サムネを裏切らない。地震や災害の不安をあおらない（事実は落ち着いて、怖がらせる言い方をしない）。
- 聞き違えやすい言葉を避ける。読みを間違えそうな地名・用語は（よみ）を書く。
- 最後：まとめ→「次回も、地図に残る、もうひとつの『なぜ』を、たどっていきます。」。次回の題材名は書かない（相談前のため）。最後の約20秒は字のない地図（終了画面用）。
